# Verbatim Recorded Demo Script

1. Meet Verbatim, a local-first transcription workspace for managed corporate endpoints.
2. This demonstration uses synthetic, non-sensitive audio. The media, model, and job data stay on this device.
3. After authorization is confirmed, Verbatim validates the MP4, extracts its audio, and runs Whisper in a killable, time-bounded local worker.
4. The completed review links each transcript segment back to the source video.
5. Search narrows the transcript instantly, while the source remains one click away.
6. Deterministic analysis surfaces key moments, action candidates, questions, and recurring terms for human review.
7. Exports include text, captions, review notes, and a provenance-rich JSON evidence package.
8. The readiness panel confirms local media tools, model availability, and zero network requirement.
9. Deletion is explicit and removes the synthetic source and its derived artifacts.
10. The end-to-end demonstration is complete. Pilot use remains subject to the documented security and records-management conditions.

Claim boundary: this recording demonstrates one controlled synthetic fixture. It does not establish general accuracy, production security, compliance, or ROI.
