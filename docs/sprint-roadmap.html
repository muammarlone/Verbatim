Phase 1 — Pilot Gate Sprints
Sprint sequence below is the recommended parallel execution order (fastest-close first). SP-04 (QG-05) can close in <1 day with DPO action. SP-03 (QG-03) has the longest lead time and should start immediately.

Warning: Current WER thresholds (0.15/0.20/0.25) are labeled ASSUMPTION in evidence/eval/threshold-protocol.json. They have no domain SME sign-off. Do not claim accuracy targets as validated until this sprint closes.
Stories
  • STS-104 Provide ≥20 real authorized corporate recordings covering target verticals (legal, medical, finance)
  • STS-104 Define consequential error categories per vertical (e.g., medication names, party names)

  • STS-104 Commit sealed dataset card and eval results with human-accepted thresholds
Done criteria

Non-Goals & Permanent Constraints
Not in scope — everReason
Cloud transcription (sending audio to any external API)Core architecture decision ADR-001. Local-only is the security and privacy foundation.
"100% accuracy" or unqualified quality claimsProhibited by QG-08 governance. Only validated thresholds with named human sign-off are permitted.
Multi-user or server deploymentSingle-user, loopback-only. Multi-user requires separate identity, ACL, and session-management architecture.
Automatic redactionRedaction is always reviewer-approved per export. No automated removal of content permitted.
Audit tree export to end users or analyticsNon-waivable covenant: AUDIT_SINGLE_PURPOSE_PRINCIPLE.md. Sole purpose = product defensibility.
Connectors before pilot gate passesPhase 1 trust baseline must close first. Connectors have separate threat models and ADR gates.
Production credentials in Codespaces or dev environmentsPermanent security constraint. Codespaces = synthetic/mock data only.
Self-signing the MSIX installerBuild scripts never self-assign VERBATIM_INSTALLER_PRODUCTION_READY. EV cert is IT-only gate.
